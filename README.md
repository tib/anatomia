# Anatómia

Statikus, böngészőben közvetlenül megnyitható anatómiai áttekintő. Nincs buildlépés és nincs Node.js-függőség.

## Helyi megnyitás

Nyisd meg az `index.html` fájlt böngészőben. Az oldal alapértelmezésben az **Izomzat** modult mutatja. A **Csontok** és **Ízületek** választó már működik; ezekhez később kerül tartalom.

## Közzététel

A repó gyökere statikus webgyökérként használható, például GitHub Pages alatt a `main` ágból és `/ (root)` mappából.

## Képek

A képek a `assets/` könyvtárban vannak. Néhány, letöltési korlát miatt közvetlen Wikimedia Commons-képként hivatkozott ábra hálózati kapcsolatot igényel; ha nem érhető el, az oldal helyi testtájábrára vált. Az egyes képek forrása és licence az adatlap ↗ jelére kattintva érhető el.
